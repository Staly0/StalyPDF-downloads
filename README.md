# StalyPDF surum indirmeleri

Bu depo yalnizca derlenmis StalyPDF surumlerini barindirir. Kaynak kod ozel
depoda tutulur; burada indirilebilir dosyalar vardir.

Istediginiz surumu [Releases](https://github.com/Staly0/pdf_toolkit-downloads/releases)
sekmesinden indirin.

## Kurulum notlari

- **Windows:** ZIP'i acin ve icindeki `stalypdf.exe` dosyasini calistirin.
  "VCRUNTIME140.dll bulunamadi" hatasi alirsaniz
  [Visual C++ yeniden dagitilabilir paketini](https://aka.ms/vs/17/release/vc_redist.x64.exe)
  kurun.
- **macOS:** ZIP'i acin, `stalypdf.app` dosyasini Applications klasorune tasiyin.
  Ilk acilista Gatekeeper uyarisi cikarsa uygulamaya sag tiklayip **Ac** deyin.
- **Android:** APK dosyasini acin. Android "bilinmeyen uygulama" uyarisi verir;
  Ayarlar > Uygulamalar > Bilinmeyen uygulamalar yolundan izin verin.
